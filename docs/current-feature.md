# 当前功能说明

**Date:** 2026-05-15

**Status:** Current `master` baseline

建议先读这份文档，再看 [当前版本原型](current-prototype.md)。

## 1. 产品定位

这是一个基于微信小程序、云开发和云托管的 NFC 写卡工具，目标是把常见的“打开应用 / 播放音乐 / 打开网页 / 连接 WLAN / 播放本地音视频”几类动作快速写入 NFC 标签。

当前版本已经形成两条主能力：

- **直接写卡能力**：应用、音乐、网页、WLAN 四类信息可直接在小程序里生成 NDEF 记录并写入标签。
- **云端媒体能力**：本地音视频文件可以先上传到云端生成播放页，再把播放页链接写入 NFC；用户后续还能在“我的文件”里复用、复制或删除这类记录。

## 2. 信息架构

### 2.1 小程序页面

- `pages/write-menu/write-menu`
  首页，展示 5 个写卡入口。
- `pages/write-app/write-app`
  应用写卡页。
- `pages/write-music/write-music`
  音乐写卡页。
- `pages/write-web/write-web`
  网页写卡页。
- `pages/write-wifi/write-wifi`
  WLAN 写卡页。
- `pages/write-local-media/write-local-media`
  本地音视频上传与写卡页。
- `pages/my-files/my-files`
  已上传媒体文件管理页。

### 2.2 共享组件

- `components/scan-dialog`
  统一的 NFC 贴卡、写入中、成功、失败弹层。
- `components/pixel-navbar`
  统一顶部导航。
- `components/pixel-toast`
  统一轻提示。
- `components/pixel-icon`
  统一像素风图标。

### 2.3 后端与云端

- `wx-app/cloudfunctions/media-share-service`
  负责媒体上传预处理、文件建档、分享记录生成、文件列表和删除。
- `web-service`
  提供三种主题的播放页和分享详情接口。

## 3. 首页与全局行为

### 3.1 首页入口

首页当前展示 5 张入口卡片：

- 应用专区
- 音乐专区
- 网页专区
- WLAN 专区
- 本地音视频

### 3.2 首页弹层

首页当前包含三个全局弹层：

- **开发者承诺**
  首次进入时展示，说明本地音视频上传、云存储和删除失效的影响。
- **当前设备不支持写卡**
  iPhone 微信客户端进入首页时直接展示，提示当前设备不能作为本项目的 NFC 写卡端使用，并引导改用 Android 设备。
- **NFC 不可用**
  当非 iOS 设备不支持 `wx.getNFCAdapter()` 时展示，提示当前设备无法进行 NFC 写入。

### 3.3 NFC 能力门禁

当前首页对入口的门禁策略不是完全一致的：

- iPhone 微信客户端进入首页后，会直接弹出“当前设备不支持写卡”提示。
- `应用 / 音乐 / 网页 / WLAN` 进入前会先检查 NFC 是否可用。
- `本地音视频` 在非 iOS 设备上仍允许直接进入，即使设备当前不支持 NFC，也可以先上传、生成播放页或管理文件。

这个差异是当前版本的真实行为，应视为既定产品表现。

### 3.4 全局动效

当前版本已经补上一套轻量像素动效系统，主要用于：

- 页面主体进入时的轻微淡入与上浮
- 首页入口卡片的分层入场
- 按钮、卡片、Tab 的按压反馈
- 对话框、底部选择器、Toast 的出现动效

这套动效以“短、轻、不断操作”为原则，不做大面积持续闪动，也不依赖复杂的长时动画。

## 4. 页面功能说明

### 4.1 应用写卡

应用写卡页当前提供：

- 应用分类选择器
- 预置应用列表
- 自定义包名输入
- 粘贴剪贴板内容

当前真实能力以 **Android 包名直达** 为主：

- 页面最终写入的是 `android.com:pkg` 类型记录。
- Android 下，用户可以从预置应用里直接选包名，也可以在“自定义”场景手输包名。
- 页面不再展示 iOS 选择入口。

### 4.2 音乐写卡

音乐写卡页当前支持：

- 手动输入或粘贴分享链接
- 解析中状态
- 成功后写入一组组合记录

当前仅支持两类来源：

- `网易云音乐` 短链
- `QQ 音乐` 分享链接 / 歌曲详情链接

写卡时并不是只写一个网页链接，而是会组合写入：

- 一个音乐 App 唤起 URI
- 一个 Android 包名记录

因此它更接近“打开指定音乐 App 并定位歌曲”，而不是普通网页跳转。

### 4.3 网页写卡

网页写卡页当前支持：

- 手动输入或粘贴 URL
- URL 格式校验
- 对未带协议的输入自动补 `https://`
- 成功后写入标准 URI 记录

页面会在输入阶段实时更新是否可写入，只有通过校验的链接才允许打开写卡弹层。

### 4.4 WLAN 写卡

WLAN 写卡页当前是一个轻量流程：

1. 进入页面后尝试初始化 WLAN 模块
2. 尝试读取当前已连接网络作为默认选项
3. 用户点击选择器打开 WLAN 底部弹层
4. 页面按需扫描附近 WLAN
5. 用户选中一个 WLAN 后输入密码
6. 页面写入标准 Wi-Fi NDEF 记录

当前页面结构已经收敛为：

- 一个 `WLAN` 选择框
- 一个密码输入框
- 一个密码明文/密文切换按钮
- 一个主写卡按钮
- 一个底部弹出的 WLAN 选择器

当前页面不再额外展示：

- “当前网络”标签
- 信号强度
- 大段环境说明

当前真实能力与限制如下：

- 面向 **Android** 使用场景
- 默认优先带出当前已连接 WLAN
- 扫描附近 WLAN 时才处理定位相关权限
- 支持打开微信定位权限引导
- 当前写入格式为 `application/vnd.wfa.wsc`
- 当前版本聚焦 `WPA2-Personal`

当前不支持：

- iPhone NFC 配网流程
- 开放网络
- WEP
- 企业网络
- 隐藏网络专门配置
- 密码缓存、云同步或历史复用

### 4.5 本地音视频写卡

本地音视频页是当前功能最完整的一条链路，包含：

- 从微信会话选择文件
- 文件类型与大小校验
- 文件信息卡片展示
- 三种播放页主题选择：`Pixel / Minimal / Poster`
- 上传、登记、生成分享页三个阶段的加载遮罩
- 成功后打开 NFC 写卡弹层

当前允许的文件类型与大小：

- 音频：`mp3 / m4a / wav`，上限 `10MB`
- 视频：`mp4`，上限 `20MB`

页面当前还支持一种“复用模式”：

- 如果用户从“我的文件”进入本页复用已有记录，就不需要重新上传文件，只会重新生成分享页并写卡。

当前版本已经修正一个关键交互：

- 当用户选到无效文件时，页面会保留文件名和错误信息用于说明，但主按钮不会误进入可提交状态。

### 4.6 我的文件

“我的文件”当前用于管理本地音视频写卡记录，功能包括：

- 查看文件列表
- 查看总文件数和总云端占用
- 空态提示
- 复用记录重新写卡
- 复制最近一次播放页链接
- 删除文件及其关联分享记录

删除后会有一个明确影响：

- 文件被删除后，与之关联的播放页链接和已写入 NFC 的链接都会失效。

列表读取当前采用分页上限策略：

- 页面展示最近 50 条文件记录
- 统计信息仍会汇总当前用户的总数量和总容量

## 5. 共享写卡弹层

所有写卡页当前共用 `scan-dialog`。

弹层统一包含 4 个状态：

- `waiting`：等待贴近标签
- `writing`：写入中
- `success`：写入成功
- `error`：写入失败

当前版本已经补强了两个重要行为约束：

- 写卡成功后不会在弹层还停留时继续接受新的标签触发
- 写卡失败后同样保持锁定，只有用户关闭或点“重试”才会继续下一轮发现

本地音视频页在成功态下还额外提供：

- 继续写入
- 回到“我的文件”

这也是当前唯一在成功态提供第二动作按钮的页面。

## 6. 数据与系统依赖

### 6.1 云开发依赖

本地音视频能力依赖微信云开发环境，核心数据集合包括：

- `media_files`
- `media_shares`

### 6.2 云端播放页

播放页服务当前提供三套主题：

- `pixel`
- `minimal`
- `poster`

分享链接格式由小程序统一拼接为：

```text
<PLAY_BASE_URL>/play/<themeKey>/<shareId>
```

播放页通过接口读取分享详情，再根据媒体类型加载音频或视频资源。

## 7. 当前限制与非目标

当前版本明确不做以下范围：

- 微信 iPhone 客户端中的通用 NFC 写卡能力
- 音乐平台的广泛扩展支持
- WLAN 的开放网络 / WEP / 企业网 / 隐藏网络支持
- 本地音视频的断点上传、批量上传、历史版本管理
- 通用 NFC 读卡与反向解析
- 把媒体记录做成跨端同步文件库产品

## 8. 当前版本验收重点

如果以当前版本做联调或验收，建议重点确认以下链路：

1. 首页 5 个入口与两个弹层显示是否正确
2. 应用写卡是否能正确写入 Android 包名记录
3. 音乐写卡是否能解析 `网易云 / QQ 音乐` 分享链接
4. 网页写卡是否能正确补全协议并写入 URI
5. WLAN 写卡是否能默认带出当前网络、切换网络、输入密码并写入
6. 本地音视频是否能完成上传、建档、生成播放页、写卡
7. “我的文件”是否能复用、复制和删除记录
